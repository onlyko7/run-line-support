PRIVACY

プライバシーポリシー

Run Lineは、ランニングチャレンジの管理に必要な情報のみを取り扱い、ヘルスデータの保護を大切にしています。

施行日：2026年11月7日

1. 取り扱う情報と利用目的

Run Lineは、チャレンジ機能の提供と進捗計算のため、ユーザーが入力したチャレンジ名、スタート地点と目的地の座標、チャレンジの状態、走行距離、日付を取り扱います。これらの情報はアプリの機能提供のためユーザーの端末に保存されます。

チャレンジごとにヘルスケア連携の開始日を設定し、アクセスを許可した場合、アプリはその日以降のランニングワークアウトと、それに紐づく距離情報を読み取り、チャレンジの距離記録に反映します。HealthKitから読み取った健康・運動情報を広告やマーケティングに利用したり、第三者に提供したり、Run Lineのサーバーへ送信したりすることはありません。

新しいチャレンジの作成画面で地図の初期表示位置を設定するため、端末の現在地へのアクセスを求める場合があります。現在地は地図の初期表示のみに使用し、チャレンジデータとして保存したり、Run Lineのサーバーへ送信したりしません。

2. 保存と保管期間

チャレンジと距離記録はユーザーの端末に保存されます。アプリの設定からデータをリセットした場合、またはアプリを削除した場合、アプリに保存された情報が削除されることがあります。Appleヘルスケアの元データをRun Lineが作成、変更、削除することはありません。

3. 第三者サービス

アプリは地図表示のためにGoogle Maps SDK for iOSを使用する場合があります。地図サービスの提供に伴ってGoogleが取り扱う情報には、Googleのプライバシーポリシーが適用される場合があります。詳しくはGoogleプライバシーポリシーをご確認ください。

4. ユーザーの選択と権利

位置情報とヘルスケアのアクセス権限は、端末の設定から変更できます。権限を許可しない場合でも、距離の手動入力など、その権限を必要としない機能を利用できます。アプリ内のデータリセット機能を使って、端末内のチャレンジ、距離記録、設定を削除できます。

5. お子様の個人情報

Run Lineの対象ユーザーと年齢制限については、App Storeに掲載されたアプリ情報をご確認ください。運営者は適用される法令に従ってお子様の個人情報を保護します。
