# Run Line 서포트 페이지

GitHub Pages로 배포할 정적 사이트 파일입니다.

GitHub Pages의 배포 원본은 이 `github-pages/` 폴더로 지정합니다. 상위 `dist/` 폴더는 이전 초안이므로 배포 원본으로 사용하지 않습니다.

- `index.html`: 앱 지원 및 사용 안내
- `privacy.html`: 개인정보 처리방침
- `styles.css`: 공통 스타일
- `run-line-app.jpg`: 서포트 페이지 대표 이미지

문의 이메일은 mechaoppa@gmail.com으로 등록했습니다. 운영자 이름은 공개하지 않으며, 개인정보 관련 문의도 같은 이메일로 접수합니다. 게시 전 최종 앱 동작 및 제3자 SDK 설정과 개인정보 처리방침의 내용이 일치하는지 확인해야 합니다.
