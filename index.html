Q지도 위 직선은 실제 러닝 경로인가요?
아니요. 출발지와 목적지 사이의 직선은 챌린지 진척을 보여주는 시각화입니다. 실제 도로나 이동 경로, GPS 러닝 기록을 표시하지 않습니다.
Q거리를 직접 입력할 수 있나요?
네. 러닝 후 거리와 날짜를 직접 입력할 수 있습니다. 건강 앱 연동 여부와 관계없이 수동 입력을 이용할 수 있습니다.
Q건강 앱 기록과 직접 입력한 기록이 중복되면 어떻게 하나요?
같은 날짜의 건강 기록과 수동 기록은 각각 표시되며 기본적으로 둘 다 누적 거리에 합산됩니다. 같은 달리기라면 ‘건강 기록과 중복 가능’ 표시가 있는 수동 기록을 왼쪽으로 밀어 삭제하세요. 삭제 전에 확인할 수 있고, 삭제 후 잠시 실행 취소할 수 있습니다.
Q챌린지와 기록은 어디에 저장되나요?
챌린지와 거리 기록은 앱이 설치된 기기에 저장됩니다. 앱을 삭제하거나 데이터를 초기화하면 로컬 데이터가 삭제될 수 있으니 유의해 주세요.
Q기록을 수정하거나 삭제할 수 있나요?
진행 중인 챌린지에서는 수동으로 입력한 기록을 수정하거나 삭제할 수 있습니다. 건강 앱에서 가져온 기록은 앱에서 수정·삭제할 수 없으며, 완료한 챌린지의 기록은 조회만 가능합니다.
Q완료한 챌린지를 다시 수정할 수 있나요?
완료된 챌린지와 기록은 조회 전용입니다. 완료 챌린지 이력에서 챌린지를 삭제하면 연결된 기록도 함께 삭제됩니다.
Q데이터 초기화는 건강 앱 기록에도 적용되나요?
아니요. 데이터 초기화는 Run Line에 저장된 챌린지, 거리 기록과 설정만 이 기기에서 삭제합니다. 건강 앱의 원본 워크아웃 데이터는 변경하지 않습니다.
Q앱 언어는 어떻게 바꾸나요?
Run Line 앱 안에는 언어 선택 메뉴가 없습니다. iPhone 설정에서 앱 > Run Line > 언어를 열어 한국어 또는 일본어를 선택하세요. 이 서포트 페이지의 언어 선택은 웹페이지에만 적용됩니다. iOS 버전에 따라 설정 항목의 이름이나 위치가 다를 수 있습니다.
