개인정보 처리방침

Run Line은 러닝 챌린지를 관리하는 데 필요한 정보만 처리하며, 건강 데이터 보호를 중요하게 생각합니다.

시행일: 2026년 11월 7일

1. 처리하는 정보와 목적

Run Line은 사용자가 입력한 챌린지 이름, 출발지와 목적지 좌표, 챌린지 상태, 달린 거리와 날짜를 챌린지 제공 및 진척 계산 목적으로 처리합니다. 이 정보는 앱 기능을 위해 사용자의 기기에 저장됩니다.

사용자가 챌린지별 건강 앱 연동의 시작일을 정하고 권한을 허용한 경우, 앱은 해당 시작일 이후의 러닝 워크아웃과 해당 워크아웃에 연결된 거리 정보를 읽어 챌린지의 거리 기록에 반영합니다. 건강 정보는 읽기 용도로만 사용하고 앱 자체 서버로 전송하지 않습니다.

새 챌린지 생성 화면의 지도 초기 위치를 설정하기 위해 기기의 현재 위치 권한을 요청할 수 있습니다. 현재 위치는 지도 초기 표시 용도로만 사용하고 앱의 챌린지 데이터로 저장하거나 앱 자체 서버로 전송하지 않습니다.

2. 저장 및 보관

챌린지와 거리 기록은 사용자의 기기에 저장됩니다. 앱 설정에서 데이터 초기화를 실행하거나 앱을 삭제하면 앱에 저장된 정보가 삭제될 수 있습니다. 건강 앱의 원본 데이터는 Run Line이 생성·수정·삭제하지 않습니다.

3. 제3자 서비스

앱은 지도 표시를 위해 Google Maps SDK for iOS를 사용할 수 있습니다. 지도 제공 과정에서 Google이 처리하는 정보에는 Google의 개인정보 보호 정책이 적용될 수 있습니다. 자세한 내용은 Google 개인정보처리방침을 확인해 주세요.

4. 이용자의 선택과 권리

위치 권한과 건강 앱 권한은 기기의 설정에서 변경할 수 있습니다. 권한을 허용하지 않아도 수동 거리 입력 등 해당 권한이 필요하지 않은 앱 기능을 이용할 수 있습니다. 앱 내 데이터 초기화 기능을 통해 로컬 챌린지, 거리 기록 및 설정을 삭제할 수 있습니다.

5. 아동의 개인정보

Run Line의 대상 이용자와 연령 제한은 App Store에 표시된 앱 정보를 확인해 주세요. 운영자는 적용되는 법령에 따라 아동의 개인정보를 보호합니다.

6. 방침 변경 및 문의

앱 기능이나 관련 법령 변경에 따라 이 방침을 수정할 수 있으며 변경 내용과 시행일을 이 페이지에 게시합니다. 개인정보 처리와 관련된 문의는 아래 이메일로 접수할 수 있습니다.
